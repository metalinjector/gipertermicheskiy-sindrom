# Гипертермический синдром

> Иллюстрированное методическое пособие по распознаванию, дифференциальной
> диагностике, неотложной помощи и профилактике гипертермических состояний.

Материал рассчитан на студентов старших курсов, ординаторов и врачей,
которым нужен последовательный маршрут от физиологии теплообмена до действий
при тепловом ударе, злокачественной гипертермии, нейролептическом злокачественном
и серотониновом синдромах.

> [!CAUTION]
> Это учебное пособие, а не локальный клинический протокол. При реальном
> пациенте действуют актуальные национальные и локальные рекомендации,
> привлекают токсиколога, анестезиолога-реаниматолога и профильных специалистов.
> Дозы всегда сверяют с действующей инструкцией, возрастом, массой тела,
> беременностью, функцией органов и условиями конкретного учреждения.

## Как пользоваться пособием

- **Первое чтение:** главы 1–4 дают общую модель терморегуляции и причин.
- **Клиническое ядро:** главы 5–9 ведут от симптомов к диагностике и лечению.
- **Закрепление:** главы 10–15 посвящены профилактике, исходам, особым группам,
  исследованиям, разбору случаев и контролю знаний.
- **Визуальная навигация:** в каждой главе есть две иллюстрации GPT Image 2,
  точные подписи и проверяемая Mermaid-схема для запоминания.
- **Один файл:** [`polnyy-tekst.md`](polnyy-tekst.md) автоматически собирается
  из тех же глав и не должен редактироваться вручную. Он крупный (около 600 КБ),
  поэтому GitHub показывает его исходником, без иллюстраций и Mermaid-схем, —
  для чтения открывайте отдельные главы или PDF.

## Ключевой маршрут

```mermaid
flowchart TD
    A["Контекст риска или триггер"] --> B["Изменение сознания / тяжёлое состояние"]
    B --> C["ABCDE + надёжная температура ядра"]
    C --> D["Немедленная поддержка и эффективное охлаждение"]
    D --> E["Причинная ветвь: тепло / MH / НЗС / СС / другое"]
    E --> F["Повторный контроль органов и осложнений"]
```

## Доказательная база

Спорные утверждения проверены по рецензируемой литературе с помощью Scite,
а клинические алгоритмы — по первичным руководствам MHAUS, EMHG, CDC/NIOSH,
Wilderness Medical Society, FDA и профильным консенсусам. Список источников,
границы доказательности и дата аудита: [`ИСТОЧНИКИ.md`](ИСТОЧНИКИ.md).

**Что важно знать читателю о позиции пособия:**

- **Цвет кожи не управляет охлаждением.** Мраморность и холодные конечности при
  непирогенной гипертермии означают шок; его лечат параллельно с охлаждением, а
  не вместо него. Деление на «красную» и «белую» гипертермию описывает фазы
  гемодинамики, а не два заболевания с противоположной тактикой.
- **Педиатрическая «белая» лихорадка — отдельный контекст.** Национальный
  протокол со спазмолитиком относится к *пирогенной лихорадке инфекционного
  генеза* и не переносится на тепловой удар (§ 12.1.6, § 14.5).
- **Специфическая терапия доказана только при MH.** Дантролен обязателен при
  злокачественной гипертермии; при НЗС данные 2026 года не подтверждают его
  рутинного применения (§ 13.2.4).
- **Пороги и проценты — ориентиры, а не законы.** Пособие избегает формулировок
  вида «выше X °C повреждение необратимо» и «каждый час добавляет Y %
  летальности»: они создают ложную точность.

## Локальная работа

```bash
git clone https://github.com/metalinjector/gipertermicheskiy-sindrom.git
cd gipertermicheskiy-sindrom
python3 scripts/audit_markdown.py     # проверка структуры и ссылок
python3 scripts/build_full_text.py    # пересборка polnyy-tekst.md из глав
```

**Правило редактирования.** Единственный источник правды — файлы в `главы/`.
`polnyy-tekst.md` целиком генерируется из них и правится только пересборкой:
ручная правка будет затёрта при следующем запуске `build_full_text.py`.
Пересборку запускают по необходимости, а не после каждого изменения главы, —
расхождение в промежутке ожидаемо. При конфликте слияния в `polnyy-tekst.md`
его не разрешают руками, а пересобирают из уже разрешённых глав.

Для внесения изменений используйте собственный GitHub-доступ. Не публикуйте
токены в README, URL удалённого репозитория, истории команд или коммитах.
